# 3d-print-quote

给 AI 用的 3D 打印报价 skill。丢一个模型文件进去，算出成本、报价和完整的参数明细。

零依赖，Python 标准库就能跑（不用 numpy、不用 trimesh）。

## 它解决什么

3D 打印报价的麻烦不在算术，在于**每一步都有假设，而这些假设通常没人说**。

这个 skill 的三条原则：

1. **真值优先** —— 切片文件里的耗材量和时长是真值，能读就读；读不到才估算
2. **假设必须出声** —— 填充按多少、单位怎么判、机时算没算，全都要写在报价里
3. **不指望靠打印赚钱** —— 机时按折旧算（示例 ¥1.2/h），目标是「不亏 + 够快」，不是「赚最多」

## 快速开始

```bash
# 1. 体检：这个文件能算多准、该走哪条路
python scripts/analyze.py 你的文件.gcode.3mf

# 2. 报价
python scripts/quote.py --mass 103.41 --material PLA --hours 2.79 --waste 0.12

# 3. 查材料（41 种）
python scripts/materials.py PLA
```

`analyze.py` 会输出一个 `quote_path` 字段，直接告诉你下一步怎么算，不用自己判断：

| `quote_path` | 含义 | 下一步 |
|---|---|---|
| `true_mass` | 有 GCode，拿到耗材真值和时长 | 用 `--mass` + `--hours`，损耗 12% |
| `estimated` | 没有真值，只有几何 | 用 `--volume --fill 0.25`，损耗 20%，机时不计 |
| `blocked` | 真值和几何都没有 | 先处理告警 |

## 三种输入，三种精度

| 输入 | 你能拿到什么 | 准不准 |
|---|---|---|
| 切片产物 `.gcode` / `.gcode.3mf` | 耗材真值、时长、层高、料型 | 准 |
| 工程 3MF（Bambu / Orca 导出） | 几何 + 切片参数（填充率、支撑、壁厚） | 耗材估算 |
| 纯几何 `.stl` / 普通 `.3mf` | 几何体积 | 耗材估算，机时算不了 |

**判断依据是文件里装了什么，不是扩展名。** 同样是 `.3mf`，可能是切片包、工程文件或纯几何。

## 为什么需要填充系数

STL 给的是**实心体积**——把模型当成一整块塑料。但真实打印不是实心的，有填充率、壁厚、顶底层和支撑。

实测配对样本（同一件的几何文件和切片文件）：

| | 值 |
|---|---|
| 几何体积 | 355.139 cm³ |
| × PLA 密度 1.24 → 实心质量 | 440.4 g |
| GCode 里的实际耗材 | **95.57 g** |
| 实际 / 实心 | **21.7%（实心算法高估 4.6 倍）** |

所以几何路径默认按 **25%** 换算。注意这 25% 不是切片软件里那个「填充率」滑块——那个通常只有 10~15%，因为它不含壁厚、顶底层和支撑。**拿 15% 直接当系数会低估约 40%。**

不同模型这个比值差异很大（工作区的样本分布在 5%~15% 的填充设置），25% 是拍板的默认值，不是统计结果。要更准就上传切片文件。

## 文件结构

```
3d-print-quote/
├── SKILL.md                    # 给 AI 看的操作手册
├── README.md
├── references/
│   └── materials.md            # 41 种材料：密度 + 参考进价
├── scripts/
│   ├── analyze.py              # 文件解析 + 体检，输出 JSON
│   ├── quote.py                # 纯算术，不碰文件
│   ├── materials.py            # 查材料表
│   └── mesh.py                 # 零依赖 STL/3MF 网格解析
└── tests/
    └── cube_10mm.stl           # 10mm 标准立方体，回归样本
```

**改价格只改 `references/materials.md`**，脚本每次实时读那张表，没有第二份数据要同步。表里「你的单价」列填了就优先用你的。

## 默认值都是示例

机时费率、毛利率、材料进价这三项请按自己的机器、渠道和预期改一遍。默认值只是能让流程跑起来的起点，不是推荐值。

| 参数 | 默认 |
|---|---|
| 毛利率 | 30%（报价 = 成本 ÷ 0.70，不是 ×1.30） |
| 机时费率 | ¥1.2/h（折旧口径） |
| 填充系数（几何路径） | 25% |
| 损耗率 | 切片路径 12% / 几何路径 20% |
| 开机费 | 0（隐藏项，用户不提就不管） |

## 已知边界

- 后处理工时（去支撑、打磨、喷漆）没进模型，目前靠开机费粗略覆盖
- 批量同盘打印的机时不是简单 × 数量，暂按件数线性计
- 填充系数只有一个配对样本，没有按尺寸分档的实测依据
- 填充系数默认 25% 对薄壳 / 花瓶模式件会低估
- 比表面积可作薄壁代理指标，尚未校准阈值

## 回归验证

`tests/` 里三个样本，各覆盖一个分支：

| 样本 | 覆盖什么 | 预期结果 |
|---|---|---|
| `cube_10mm.stl` | 体积算法正确性 | 体积 1.0000 cm³、面积 600.00 mm²、包围盒 10×10×10、水密 True，与理论值完全一致 |
| `open_cube_10mm.stl` | 不封闭网格 | 触发 `NOT_WATERTIGHT` |
| `small_cube_5mm.stl` | 单位下限判断 | 触发 `UNIT_CHECK_SMALL`（5mm 疑似 inch 单位） |

```bash
for f in tests/*.stl; do python scripts/analyze.py "$f"; done
```
