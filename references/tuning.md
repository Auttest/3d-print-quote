# 参数调优

默认值为什么是这些、动哪个最有用、实测依据在哪。
**改默认值之前读一遍**，日常报价不用。

## 行业现实

大农场已经把打印服务压到 0.1 元/g，规模化之后单靠打印赚不到钱。赚钱的地方在**模型的独特性**——自研设计、别人拿不到的文件，而不是机器转速。

因此这套参数按这个现实定：

- 机时按折旧算（示例 ¥1.2/h），不指望靠机器占用赚钱
- 开机费默认 0，用户不提就不管，不靠它凑数
- **目标是「不亏 + 够快」，不是「赚最多」**

**自研模型不适用成本加成**：卖自己设计的模型，价格该按价值定，不是按克重和机时累加。那种情况下这工具只用来确认「低于多少不卖」。

## 敏感度实测

基准：95.57g / 5.86h / PLA 0.045 元/g，报价 ¥16.93。

| 变动 | 报价影响 |
|---|---|
| 开机费 0 → ¥30 | **+253%** |
| 机时费率 ×2（1.2 → 2.4） | +59% |
| 毛利率 30% → 40% | +17% |
| 材料进价 +33% | +14% |
| 打印时长 +15%（改层高） | +9% |
| **损耗率 12% → 20%** | **+3%** |

**照这张表分配注意力：**

- **损耗率别纠结**——它挂在材料费上，材料费占比本就不高。定个数就行，别反复权衡
- **开机费是小单的最大杠杆**——从 0 加到 30 报价翻三倍半，所以低总价提醒那条规则不能省
- **机时费率和毛利率是常规单的主旋钮**——按你的机器和预期认真定一次，定完别老动
- **打印时长是中等杠杆**——+15% 时长报价才 +9%。但工具不主动建议改层高，那是工艺决策

## 为什么机时必须算

两个真实件对比（金额按当时的 ¥10/h 机时费率算，当前默认已改为 ¥1.2/h，数字会小一个量级，但结论方向不变）：

| | 切片件A | 支架件 |
|---|---|---|
| 克重 | 103.41 g | 95.57 g |
| 时长 | 2h 47m | 5h 05m |
| 纯克重报价 | ¥63.97 | ¥62.62 |
| 含机时报价 | ¥106.90 | ¥140.93 |

克重差 8%，纯克重报价差 2 块，机器占用差 82%。**按克重报价，大件就是白干。**

## 二维分级

参数不只按「怎么拿」分级，还要按「动它值不值」分级。两个维度正交：

| 参数 | 怎么拿 | 影响力 | 处理方式 |
|---|---|---|---|
| 开机费 | 隐藏默认 | 极高（小单） | 不主动加，但低总价必须提醒 |
| 机时费率 | 纯默认 | 高 | 按你的机器定一次 |
| 毛利率 | 纯默认 | 高 | 定一次，别老动 |
| 填充系数 | 纯默认 | **极高（几何路径）** | 默认 25%，用户不提就别管，但必须声明是估算 |
| 材料进价 | 纯默认 | 中 | 常用料填一下即可 |
| 打印时长 | 自动读 | 中 | 按文件算，不擅自改 |
| 损耗率 | AI 判断 + 声明 | **低** | 别纠结，默认就行 |
| 材料 / 数量 | 必问或自动读 | — | 缺了算不了 |
