# 材料表

**口径：纯进货价（元/克）**。机时费在报价里单独按小时算，所以这里的单价**只包含材料本身**，不能填入含机器摊销的综合价（否则机器成本算两次）。

密度是物理常数，可直接用。**价格是 2026-10 的国内行情采样**，渠道和批量影响很大，仅供起步，填上你的实际进价后以你的为准。

| 字段 | 含义 |
|---|---|
| 密度 | 物理常数，可靠 |
| 参考进价 | 国内主流渠道中位，元/克 |
| 置信 | 高＝多渠道印证；中＝单一来源；低＝工业渠道，必须询价 |
| 你的单价 | 留出给你覆盖，填了就用你的 |

- **行业研究报告**（2026 全球 3D 打印粉末与树脂市场）：PA11/PA12 粉末 40–100 美元/kg、通用光敏树脂 40–120 美元/kg、工程级树脂 100–400 美元/kg

## 怎么用

1. 常用哪几种就先填哪几种的「你的单价」，不必一次填全
2. 置信度标「低」的，报价前必须向供应商询价，别信这张表
3. 行情变了说一声「XX 料现在 X 元一克」，我改表
